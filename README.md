<b>WiFi Speed Checker</b><br>
<b> Description: </b><br>
<p>
The WiFi Speed Checker is a Python-based application that allows users to measure their internet connection speed. Utilizing the `speedtest` module, this application provides real-time download and upload speeds in both Megabits per second (Mbps) and Megabytes per second (MBps). The graphical user interface (GUI) is built using the `tkinter` library, offering a user-friendly experience.</p>

<b>Features:</b><br>
<p>
Real-Time Speed Measurement: Accurately measures and displays the download and upload speeds of your internet connection.
Dual Unit Display: Shows speeds in both Mbps and MBps for better understanding and comparison.<br>
User-Friendly Interface: The application features a clean and simple GUI with easy-to-read labels and a single button to initiate the speed test.
Responsive Design: The interface adjusts to different screen sizes, ensuring a consistent user experience.</p>

<b> How It Works:</b><b>
<p>
1. Initialization: The application initializes the `speedtest` module to find the best server for testing.
2. Speed Test: Upon clicking the "Check speed" button, the application measures the download and upload speeds.
3. Display Results: The results are displayed on the GUI, showing both Mbps and MBps values for download and upload speeds.</p>

<b> Technologies Used:</b><b>
<p>
Python: The core programming language used for the application.
speedtest-cli: A module to perform speed tests using Speedtest.net's servers.
tkinter: A standard GUI library in Python for creating the application's interface.
</p>

<b>Usage:</b><b>
<p>
1. Run the application.
2. Click the "Check speed" button.
3. View the download and upload speeds displayed on the screen.
</p>
